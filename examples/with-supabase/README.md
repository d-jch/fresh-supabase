# Fresh + Supabase password authentication

This example starts from the pinned official Fresh 2.3.3 Tailwind fixture and is
generated by this repository's `@fresh-supabase/cli` implementation. It uses
server-rendered Preact forms, POST + 303 redirects, request-scoped Supabase
clients, route-scoped CSRF middleware, and no runtime CLI dependency.

## Configure

Copy `.env.example` to a local environment file and set:

- `FRESH_PUBLIC_SUPABASE_URL`;
- `FRESH_PUBLIC_SUPABASE_PUBLISHABLE_KEY`.

Configure the matching Supabase email templates from
`supabase/templates/confirmation.html` and `supabase/templates/recovery.html`.

## Run

```bash
deno install --frozen
deno task dev
```

The sign-in page is at `/auth/sign-in`; the protected account page is at
`/account`.

## Verify

```bash
deno task check
deno task build
```

The repository's Phase 4 integration suite additionally checks the committed
structure, a mocked Supabase password-auth flow, and a Deno Deploy-mode build.
